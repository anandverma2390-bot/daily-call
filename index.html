Daily backup

Backups are written in the same encrypted form as the vault — the file is useless without a user password. A web page cannot write to your disk on a schedule. "Daily backup" here means a one-click download plus a reminder when you have not taken one today. Save the file to a synced folder (OneDrive / Google Drive) and it is off-machine.

Passwords are never stored. Each user's password unwraps the shared data key; if every password is lost the data cannot be recovered by anyone, including you.
All call data is stored AES-256-GCM encrypted. Passwords are not stored at all — each one unwraps the data key via PBKDF2-SHA256 (250,000 iterations). Without a valid password the storage and any backup file are unreadable.
Limit worth knowing: role separation is enforced by this page, not by cryptography. Any user who can log in holds the data key, so a technically capable engineer could reach records the interface hides from them. It stops casual snooping and a stolen laptop; it does not stop a determined insider. Data does not sync between devices.
